# 🪐 Priyanshu Kumar Singh | 3D Interactive Portfolio

A modern, high-performance, single-page developer portfolio featuring real-time 3D WebGL interactions powered by **Three.js**, fluid motion animations using **Framer Motion**, and sleek styling with **Tailwind CSS**.

---

## ⚡ Features

- **Interactive 3D Three.js Visuals**: Holographic cyber crystal with particle constellation, mouse cursor parallax, drag-to-rotate inertia, click shockwaves, and dynamic scroll transitions.
- **Top-Notch Animations**: Magnetic cursor glow, staggered element reveals, smooth section spy navigation, and animated skill progress meters.
- **Deep-Dive Case Studies**: Interactive project cards with architectural breakdowns and live modals.
- **Terminal System View**: Developer console display with quick system telemetry.
- **Responsive & Accessible**: Seamlessly responsive across mobile, tablet, and desktop viewports.

---

## 🛠️ Built With

- **Core**: React 18, Vite 6
- **3D Graphics**: Three.js & WebGL
- **Styling**: Tailwind CSS, PostCSS
- **Animations**: Framer Motion
- **Icons**: Lucide React

---

## 🚀 Local Development

1. **Clone the repository:**
   ```bash
   git clone https://github.com/priyanshusingh9247/Portfolio.git
   cd Portfolio
   ```

2. **Install dependencies:**
   ```bash
   npm install
   ```

3. **Start the development server:**
   ```bash
   npm run dev
   ```
   Open [http://localhost:3000](http://localhost:3000) in your browser.

4. **Build for production:**
   ```bash
   npm run build
   ```
